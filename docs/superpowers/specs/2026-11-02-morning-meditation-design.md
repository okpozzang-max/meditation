# 아침 명상 Android 앱 설계

상태: 사용자 승인 완료

## 의도

새벽에 일어난 뒤 출근 준비를 시작하기 전에 휴대폰으로 짧고 편안하게 명상을 시작하도록 돕는다. 주 사용자는 앱을 요청한 본인이며, 명상을 부담 없이 시작해 꾸준히 이어가는 것이 목적이다.

## 목표

- 앱을 열어 짧은 조작으로 명상을 시작할 수 있다.
- 1분, 5분, 10분, 15분, 20분 중 원하는 시간을 고른다.
- 자연 소리나 싱잉볼 소리를 선택하거나 소리 없이 명상한다.
- 진행 중 남은 시간을 확인하고 타이머를 일시정지·재개하거나 명상을 마칠 수 있다.
- 앱은 조용하고 읽기 쉬우며, 아침에 한 손으로 쓰기 편하다.

## 목표에서 제외

- 진행 기록, 연속 사용일, 통계, 계정, 소셜 기능, 결제, 광고, 리마인더
- 치료나 의료 효과를 약속하는 콘텐츠
- 별도 호흡 안내 프로그램이나 강좌
- 서버, 사용자 계정, 분석용 데이터 수집

## 성공 기준

- 앱을 열고 기본 설정을 그대로 사용하면 두 번 이내의 탭으로 명상을 시작할 수 있다.
- 다섯 시간 선택지와 각 소리 선택지가 휴대폰 화면에서 쉽게 식별되고 눌린다.
- 선택한 소리는 타이머가 끝나거나 사용자가 소리를 끌 때 함께 멈춘다.
- 명상 중 화면에서 남은 시간, 일시정지·재개, 종료 조작을 명확히 확인할 수 있다.
- 세션 기록이나 계정 없이 핵심 흐름 전체를 사용할 수 있다.

## 승인된 화면 방향

사용자는 어두운 숲빛 색상과 시작 화면·명상 중 화면의 임시 목업을 승인했다. 이 방향을 제품 설계의 출발점으로 삼는다.

### 시작 화면

- 첫 화면에 시간 선택, 배경 소리 선택, 시작 버튼을 둔다.
- 시간은 1·5·10·15·20분 다섯 가지이며, 목업처럼 5분을 기본 선택으로 둔다.
- 소리는 소리 없이, 숲 소리, 잔잔한 파도, 빗소리, 싱잉볼을 제공하며 숲 소리를 기본 선택으로 둔다. 사용자가 바꾼 시간·소리 선택은 기기에만 저장해 다음 실행에서 기억한다. 세션 이력은 저장하지 않는다.
- 선택 상태는 색상만이 아니라 "선택됨" 표시와 접근성 선택 상태로 알린다.
- 소리 미리 듣기는 범위에 넣지 않는다. 선택한 소리는 명상 중 재생된다.
- 시작 버튼 문구에 선택한 시간을 반영한다.

### 명상 중 화면

- 큰 숫자로 남은 시간을 보여준다.
- 선택한 소리 상태와 소리 끄기 조작을 보여준다.
- 일시정지·재개와 명상 마치기 조작을 제공한다.
- 차분한 색상과 간결한 문구를 사용한다. 기본 명상은 호흡에 대한 지시 없이 조용히 시간을 보낸다.

## 접근성 및 상호작용

- Android 터치 영역은 최소 48dp, 조작부 간격은 최소 8dp를 기준으로 한다.
- 일반 글자는 배경 대비 4.5:1 이상을 목표로 하며, 텍스트 크기 확대에도 주요 조작이 보이도록 한다.
- TalkBack에서 시간, 소리, 선택 상태, 재생 상태, 남은 시간이 명확히 읽히도록 한다.
- 모든 조작은 Android 기본 버튼 의미와 터치 피드백을 갖는다.
- 색상만으로 선택 상태나 재생 상태를 전달하지 않는다.

## 기술 및 실행 환경

저장소는 비어 있고 기존 기술 스택이나 프로젝트 지침은 없다. 사용자는 기기 모델/Android 버전을 모르는 상태이므로 일반적인 Android 휴대폰 지원을 원한다. 앱은 개인 사용을 위한 직접 설치 APK를 우선한다. 현재 실행 환경 확인에서는 Java, Gradle, Android SDK, Android Studio 경로를 찾지 못했다. 구현 시 현재 Android 도구 체계와 넓은 기기 호환성을 바탕으로 최소 Android 버전을 정한다.

### 검토한 접근 방식

1. **Kotlin + Jetpack Compose 네이티브 Android 앱 — 선택 방향.** 사용자는 Android 앱을 원한다. Android 플랫폼의 오디오 재생, 접근성, 시스템 알림, 백그라운드 동작과 자연스럽게 맞고 별도 크로스플랫폼 계층이 필요 없다. 다만 SDK와 빌드 도구를 준비해야 한다.
2. **Flutter 앱.** Android 외 플랫폼을 추가할 때 재사용성이 있다. 현재 목표는 Android 개인용 앱이므로 Dart/Flutter 도구 체계와 추가 계층이 이득보다 부담이 크다.
3. **설치형 웹 앱(PWA).** 빠르게 배포할 수 있지만 사용자가 Android 앱을 원하고, 화면이 잠겨도 소리가 이어지는 동작과 Android 시스템 통합을 별도로 검증해야 하므로 선택하지 않았다.

사용자가 선택한 것은 Android 플랫폼이다. Kotlin + Jetpack Compose는 기존 프로젝트가 없는 상황에서의 구현 권고이며, 사용자가 별도로 정한 기술 선택은 아니다.

## 오디오 및 세션 동작에 대한 제안

- 소리 파일은 앱에 포함해 네트워크 없이 재생한다. 라이선스가 명확한 공개 음원을 사용하고 필요한 경우 앱 안에 출처를 표시한다.
- 재생은 Android 미디어 오디오 포커스를 사용하며, 전화나 다른 오디오 앱의 개입 시 시스템 오디오 포커스 규칙을 따른다.
- **확정 요구사항:** 화면을 잠그거나 잠시 다른 앱으로 전환해도 타이머와 소리가 이어진다. 소리를 재생하는 세션은 Media3 미디어 세션과 `mediaPlayback` 포그라운드 서비스 유형을 사용한다. 소리 없이 타이머만 동작할 때는 Android `specialUse` 포그라운드 서비스 유형을 사용해 진행 중 세션을 표시한다. 사용자에게 보이는 알림을 제공하고 세션 종료 시 서비스와 알림을 정리한다.
- Android 공식 문서는 배경 미디어 재생에 Media3 `MediaSessionService`와 `mediaPlayback` 포그라운드 서비스 유형을 안내한다. 포그라운드 서비스 자체에는 Android 13+ 알림 런타임 권한이 필요하지 않으며, 미디어 세션 알림은 그 권한 변경의 예외다. 따라서 앱 시작 시 알림 권한 팝업을 띄우지 않고 미디어 세션의 재생·일시정지 조작을 제공한다. [배경 재생 안내](https://developer.android.com/media/media3/session/background-playback), [알림 권한 안내](https://developer.android.com/develop/ui/compose/notifications/notification-permission)
- 알림/시스템 미디어 조작부에는 재생·일시정지와 명상 마치기를 제공한다. 알림 권한이 거부된 환경에서 시스템이 포그라운드 서비스 상태를 표시하는 방식은 Android 버전에 따른다. [Android 13 동작 변경](https://developer.android.com/about/versions/13/behavior-changes-13)
- 전화나 다른 앱의 오디오 포커스 개입으로 재생이 끊기면 타이머와 소리를 함께 일시정지하고 사용자가 다시 시작하게 한다. 앱이 강제 종료되거나 기기가 재부팅된 경우 세션을 자동 재생하지 않고 다음 실행에서 시작 화면을 보여준다.
- 휴대폰 세로 화면을 우선 설계하되, 회전해도 주요 조작이 사라지지 않도록 반응형으로 배치한다. 태블릿 최적화는 이번 범위에 넣지 않는다.
- 음량은 앱에 별도 슬라이더를 추가하지 않고 기기의 미디어 음량 버튼으로 조절한다.
- 화면 잠금 중 오디오 및 소리 없는 타이머 동작은 구현 계획의 서비스 검증 단계에서 API 34+ 기기/에뮬레이터와 실제 사용자 휴대폰으로 확인한다. Android SDK/서비스 요구사항과 기기별 절전 동작은 구현 중 다시 확인한다.

## 남은 구현자 판단

- 공개 라이선스가 확인되는 숲·파도·비·싱잉볼 녹음 파일의 출처와 길이, 반복 재생의 자연스러움
- 세션 종료 시 소리를 갑자기 끊지 않도록 짧은 페이드 아웃을 적용할지 여부
- 잠금 화면 알림에 일시정지·재개·종료 중 어떤 동작을 노출할지
- 공개 라이선스가 확인되는 음원은 출처·라이선스 표기를 함께 보관하고, 세션 종료 때는 짧고 부드럽게 페이드 아웃한다.

## 제약과 주의

- 이 앱은 웰빙과 개인 명상에 도움을 주는 도구다. 치료 효과나 건강 개선을 보장하지 않는다.
- Android 도구가 현재 환경에 보이지 않아 실제 빌드·기기 설치에는 SDK/빌드 도구 준비가 필요할 수 있다. 설계 승인 전에는 설치하지 않는다.
- 현재 목업은 정적 화면 시안이며 실제 오디오나 상호작용을 구현하지 않는다.
